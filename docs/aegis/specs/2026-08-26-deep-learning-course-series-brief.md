# Deep learning course series brief

## Goal

Publish ten coherent deep-learning lessons that alternate theory and projects and can be read as a course or reviewed as portfolio material.

## Approved scope

1. Training-loop overview with PyTorch.
2. Computation graph, gradient descent, and backpropagation.
3. Training stability and overfitting diagnosis.
4. CNN and image classification.
5. Image-classification project and transfer learning.
6. RNN, LSTM, and GRU.
7. Transformer and attention.
8. TensorFlow/Keras engineering workflow.
9. PaddlePaddle Chinese text-classification project.
10. Evaluation, tuning, export, and project/interview retrospective.

## Writing contract

- Standard lessons: goals, scenario, theory, code, expected behavior, troubleshooting, exercises, interview questions, project extension, next lesson.
- Project/tuning lessons: constraints, baseline, attempts, failure analysis, final design, reference results, engineering and interview retrospective.
- Use layered mathematics: intuition in the main flow and derivation in a dedicated supplement.
- Use a neutral course voice, with first-person language only for design reasoning, never as a claim of unperformed work.

## Evidence contract

- No unattributed third-party benchmark values.
- No invented values presented as personal experiments.
- Exact synthetic metrics, when pedagogically necessary, are labeled as a reference record or example result.
- Code is reviewed for consistency, but the user does not require local model training.

## Acceptance

- Ten valid posts are present and linked as one series.
- Titles and primary lessons do not duplicate existing articles.
- Astro build succeeds.
- No new website runtime dependency or route is introduced.
- Deployment retirement remains pending exact user confirmation.
