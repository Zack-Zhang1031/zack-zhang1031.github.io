前面三篇都是监督学习——有标签、有老师。这篇进入无监督学习：数据没有标签，让算法自己发现结构。K-Means 是这个世界的入门砖：给用户分群、给文档分组、给图像压缩颜色，都能用它起步。

我用 K-Means 做过的最典型的事是用户分群：没有"谁是高价值用户"的标签，就把消费频次、客单价、活跃度扔进 K-Means，让它自己抱成几团，再人工给每团起名字。聚类的价值不在于算法多高级，在于**它能在你没有任何先验的时候，给出第一批可讨论的假设**。

## 算法逻辑：两步轮流做，做到不动为止

K-Means 的目标：把 $n$ 个点分成 $K$ 团，使每个点到自己那团中心（质心）的平方距离之和最小：

$$\min \sum_{i=1}^{n} \| x_i - \mu_{c_i} \|^2$$

这个目标函数叫**惯性（Inertia）**。算法实现出奇朴素，两步交替：

1. **分配**：每个点归入离它最近的质心那一团。
2. **更新**：每团的质心移到团内所有点的均值位置。

重复到质心不再移动（或移动小于阈值）。看代码也就十几行：

```python
from sklearn.cluster import KMeans
from sklearn.preprocessing import StandardScaler
import numpy as np

# 用户数据：消费频次、客单价、最近活跃天数
X = np.array([[12, 300, 2], [1, 50, 40], [15, 280, 1], [2, 80, 35],
              [11, 320, 3], [3, 60, 30], [14, 290, 2], [1, 70, 45]])

X_scaled = StandardScaler().fit_transform(X)   # 关键一步，下面细说

km = KMeans(n_clusters=2, n_init=10, random_state=42)
labels = km.fit_predict(X_scaled)

print(labels)            # 每个点属于哪团
print(km.cluster_centers_)  # 各团质心（标准化后的坐标）
print(km.inertia_)       # 惯性，越小抱得越紧
```

迭代收敛很快，一般几十步内就稳了。但注意：它收敛到的是**局部最优**——初始质心选得不好，结果可能很糟。这就是为什么有 K-Means++ 初始化和 `n_init` 参数。

## 关键动作一：必须标准化

K-Means 按**欧氏距离**分组。上面数据如果不标准化，"客单价"（几十到几百）会在距离计算中碾压"活跃天数"（个位数），聚类结果完全由金额主导，频次和活跃度形同虚设。

标准化（减均值除标准差）把所有特征拉到同一量纲，每个特征对距离的贡献才平等。**K-Means 前的 StandardScaler 不是可选优化，是必须步骤**——这和决策树形成鲜明对比。

## 关键动作二：K 值怎么选

K 是 K-Means 唯一的超参数，也是最头疼的。两种常用方法：

**肘部法则（Elbow）**：画 K 从 1 到 10 的惯性曲线，找"拐点"——拐点之前惯性下降很快（每加一个团收益大），之后变平（再加收益小）。

```python
from sklearn.metrics import silhouette_score
import matplotlib.pyplot as plt

Ks = range(2, 9)
inertias, silhouettes = [], []

for k in Ks:
    km = KMeans(n_clusters=k, n_init=10, random_state=42).fit(X_scaled)
    inertias.append(km.inertia_)
    silhouettes.append(silhouette_score(X_scaled, km.labels_))
```

**轮廓系数（Silhouette）**：更可靠的指标。对每个点算两个距离——到本团其他点的平均距离 $a$（内聚度），到最近邻团所有点的平均距离 $b$（分离度），轮廓系数 $s = (b - a) / \max(a, b)$，范围 [-1, 1]。越接近 1 说明"团内紧、团间远"，聚类质量高。

我的习惯是两者结合：肘部法则缩小范围，轮廓系数在候选 K 里拍板。最后还有一道人工关——**分出来的团要业务上说得通**。K=4 轮廓系数最高但四团解释不出差异，不如选 K=3。

## 关键动作三：理解 n_init 和 K-Means++

`n_init=10` 的含义：用 10 组不同的初始质心各跑一次完整的 K-Means，返回惯性最小的一次。因为每次只能收敛到局部最优，多跑几次是廉价的保险。

`init="k-means++"`（默认）是更聪明的初始化：第一个质心随机选，后续质心按"离已有质心越远概率越大"的方式选。这样初始质心天然分散，收敛更快、结果更稳。没有特殊理由不要改回 `random`。

## K-Means 搞不定的形状

K-Means 有个隐含假设：**每一团是一个球状（等方差）的凸包**。遇到以下数据它就露怯：

- **细长条/弯月形的团**：两个嵌套的新月形，K-Means 会从中间切开，因为它只认距离最近的质心。
- **密度差异大的团**：一个紧密的小团 + 一个松散的大团，小团容易被大团"吸走"边界点。
- **离群值**：几个极端点会把质心拖偏。聚类前先处理离群值，或用对离群值稳健的 K-Medoids。
- **不同尺寸的团**：一大一小两团，大团的边缘点可能离小团质心更近。

遇到非球形结构，该换 DBSCAN（按密度聚类，能发现任意形状，还能识别噪声点）或层次聚类。知道 K-Means 的边界，比会用 K-Means 更能体现水平。

## 聚类之后：结果怎么用

聚类不是终点。我的标准动作是给每团画像：把每团的特征均值拉出来对比，给团起业务名字，再验证这个分群对下游任务有没有用：

```python
import pandas as pd

df = pd.DataFrame(X, columns=["频次", "客单价", "沉默天数"])
df["cluster"] = labels

profile = df.groupby("cluster").mean()
print(profile)
# 可能得到：第 0 团 高频高价活跃 → "核心用户"
#          第 1 团 低频低价沉默 → "流失风险用户"
```

分群结果可以当新特征喂给监督模型（"用户属于哪个群"），也可以直接驱动运营策略（不同群不同的触达方式）。如果分出来的群在业务上毫无区分度，说明特征选错了——回去重做特征，而不是调 K。

## 踩坑排查清单

| 症状 | 原因 | 处理 |
|---|---|---|
| 聚类结果被单一特征主导 | 没标准化 | 聚类前必须 StandardScaler |
| 同样的数据每次结果不同 | 没设 random_state，初始化敏感 | 固定种子 + n_init=10 + k-means++ |
| 肘部曲线没有明显拐点 | 数据本身没有清晰的团结构 | 换轮廓系数验证；承认数据可能不适合聚类 |
| 某团只有一两个点 | 离群值自成一团 | 先清洗离群值 |
| 分出的团业务上解释不通 | 特征选择不当 | 重做特征工程，别硬调 K |
| 大量点轮廓系数为负 | K 值不合适或数据非球形 | 调 K；或换 DBSCAN/层次聚类 |

## 面试常问

**Q：K-Means 的收敛性有保证吗？**
有——每一步迭代（分配 + 更新）都不会让惯性增大，惯性有下界 0，所以必然收敛。但收敛到的是局部最优，不保证全局最优，这就是 K-Means++ 初始化和多次重启（n_init）存在的原因。

**Q：为什么 K-Means 对尺度敏感？**
它用欧氏距离分配样本，距离由各特征的差值平方累加。量纲大的特征差值天然大，会主导距离计算，让其他特征失效。所以聚类前必须标准化。

**Q：怎么选 K？**
没有金标准。常用肘部法则（惯性曲线拐点）和轮廓系数（内聚度 vs 分离度）取交集，最终还要业务可解释性把关：分出的群必须能起名、能对应行动，否则数学上再优也没用。

**Q：K-Means 和 KNN 有什么关系？**
除了名字都有 K，几乎无关。KNN 是监督学习：用邻居的标签投票做分类/回归；K-Means 是无监督学习：迭代移动质心把数据分团。面试里这是经典的"看你是否真的懂"陷阱题。

**Q：数据有离群值时怎么办？**
三条路：聚类前清洗（IQR 或 Z-score 识别后处理）；用 K-Medoids（PAM 算法）替代——质心必须是真实样本点，天然抗离群；或者换 DBSCAN，它会把离群点直接标记为噪声（标签 -1）。
